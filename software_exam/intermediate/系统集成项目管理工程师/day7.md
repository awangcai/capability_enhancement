## 一、信息化知识

### 1.1 信息系统生命周期
1. **立项**
2. **开发**（最关键，包含系统验收）
3. **运维**
4. **消亡**

### 1.2 国家信息化体系6要素

| 要素 | 地位 |
|------|------|
| 法规、标准 | **根本保障** |
| 信息网络 | **基础设施** |
| 信息技术应用 | **龙头** |
| 信息资源 | **关键** |
| 信息技术和产业 | **基础** |
| 信息化人才 | **根本** |

### 1.3 信息系统建设能力等级（5级）
1. 初始 2. 基本 3. 良好 4. 优秀 5. 杰出

### 1.4 大数据5V特点
- **V**olume（大量）
- **V**elocity（高速）
- **V**ariety（多样）
- **V**alue（低价值密度）
- **V**eracity（真实性）

**关键技术**：
- 存储管理：GFS、Hadoop、NoSQL、HBase
- 并行计算：MapReduce
- 分析技术

### 1.5 云计算三层服务
- **IaaS**：基础设施即服务（Infrastructure）
- **PaaS**：平台即服务（Platform）
- **SaaS**：软件即服务（Software）

### 1.6 商业智能（BI）

**组成**：数据仓库 + 数据挖掘 + 联机分析处理(OLAP) + 数据备份

**实现层次**：
1. 数据报表
2. 多维数据分析
3. 数据挖掘

**数据仓库定义**：面向**主题**的、**集成**的、**非易失**的、反映**历史变化**的数据集合

### 1.7 物联网三层架构

| 层 | 内容 |
|---|------|
| 感知层 | 传感器、摄像头、传感器网关 |
| 网络层 | 物联网管理/信息中心、通信网络 |
| 应用层 | 智能家居、工业监控、环境监测等 |

### 1.8 供应链分类（按物理结构）

| 类型 | 结构 | 特点 | 适用 |
|------|------|------|------|
| V型 | 发散性 | 原材料少、产品多 | 化工、造纸 |
| A型 | 会聚型 | 供应商多、产品少 | 航空、重工 |
| T型 | 中间型 | 适中 | 汽车配件、电子 |

### 1.9 CRM（客户关系管理）
- **以客户为中心**
- 支柱功能：市场营销、客户服务
- 构成：触发中心、挖掘中心

### 1.10 SOA与Web Service

**SOA**：面向服务的体系结构

**Web Service三种角色**：
- 服务提供者（服务器）
- 服务请求者（客户端）
- 服务注册中心

**关键协议**：
- SOAP：简单对象访问协议
- WSDL：Web服务描述语言
- UDDI：通用描述、发现与集成（用于服务注册）

## 二、信息系统集成专业技术

### 2.1 软件开发方法

| 方法 | 特点 |
|------|------|
| 瀑布 | 线性顺序，适合需求明确的项目 |
| 迭代 | 多次循环，逐步完善 |
| 敏捷 | 快速响应变化，增量交付 |
| V模型 | 开发和测试对应 |
| 原型 | 快速构建原型，获取反馈 |
| 螺旋 | 风险驱动，迭代+瀑布 |
| 面向对象 | 封装、继承、多态 |
| 结构化 | 分阶段，需全面了解需求 |

### 2.2 RUP统一过程4个阶段
1. 初始 2. 细化 3. 构建 4. 交付

### 2.3 中间件类型
1. 数据库访问
2. 远程过程调用
3. **面向消息**（实现平台无关数据传递）
4. 事务
5. 分布式对象

### 2.4 OSI七层模型（从上到下）

| 层 | 协议示例 |
|----|---------|
| 应用层 | HTTP, SMTP, FTP, POP3, DNS, DHCP, Telnet |
| 表示层 | JPEG, GIF |
| 会话层 | SQL |
| 传输层 | TCP(可靠), UDP(不可靠) |
| 网络层 | IP, ICMP, ARP, RARP |
| 数据链路层 | IEEE 802.3 |
| 物理层 | RJ45 |

> **常考协议归属**：
> - ARP（地址解析协议）→ 网络层（IP→MAC）
> - RARP（反向地址解析）→ 网络层（MAC→IP）
> - DNS → 应用层
> - TCP → 可靠、面向连接、全双工
> - UDP → 不可靠、无连接

### 2.5 网络标准

| 标准 | 内容 |
|------|------|
| IEEE 802.3 | 以太网协议 |
| IEEE 802.11 | 无线局域网标准 |
| IEEE 802.11b | 最著名、最普及 |

**传输介质标识**：F=光纤，T=双绞线

### 2.6 虚拟现实典型特征（5个）
- 沉浸性、交互性、多感知性、构想性、自主性
- **没有**真实性

### 2.7 自动驾驶等级

| 等级 | 名称 | 特征 |
|------|------|------|
| L1 | 驾驶辅助 | 定速巡航、自动泊车 |
| L2 | 部分自动化 | 大多数新车型 |
| L3 | 有条件自动化 | 驾驶员需紧绷神经观察 |
| L4 | 高度自动化 | 驾驶员可以休息 |
| L5 | 完全自动化 | 驾驶员可以放飞自我 |

## 三、信息安全

### 3.1 信息安全基本要素（至少记前3项）

| 要素 | 含义 |
|------|------|
| **保密性** | 信息不暴露给未授权实体 |
| **完整性** | 只有授权人才能修改，且可识别篡改 |
| **可用性** | 授权人可访问，攻击者不能妨碍 |
| 可控性 | 控制授权范围和行为 |
| 可审查性 | 有安全调查的依据和手段 |
| 不可抵赖性 | 行为不可否认 |

### 3.2 信息系统安全保护等级

| 等级 | 名称 | 损害对象 |
|------|------|---------|
| 1级 | 用户自主保护 | 公民法人 |
| 2级 | 系统审计 | 社会公共/公民法人 |
| 3级 | 安全标记 | 国家/社会 |
| 4级 | 结构化 | 国家(严重)/社会(特别严重) |
| 5级 | 访问验证 | 国家(特别严重) |

### 3.3 确保完整性的方法
- 数字签名
- 协议
- 纠错编码
- 密码校验和
- 公证

## 五、合同变更

**原则**：公平合理

**步骤**：
1. 先确定变更量清单，再确定变更价款
2. 合同中有适用价格 → 按已有价格
3. 合同中只有类似价格 → 参照类似价格
4. 没有类似价格 → 承包人提出，监理/业主确认后执行
