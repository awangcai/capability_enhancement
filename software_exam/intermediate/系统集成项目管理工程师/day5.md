## 一、项目风险管理

### 1.1 风险特征（必记前三点）

| 特征 | 含义 |
|------|------|
| **客观性** | 不以人的主观意志为转移 |
| **偶然性** | 信息不对称，难以预测 |
| **相对性** | 因时间、空间因素而变化 |
| 社会性 | 后果与人类社会强相关 |
| 不确定性 | 发生时间不确定 |

### 1.2 风险分类
- **纯粹风险**：只有损失没有收益
- **投机风险**：既有损失也可能有收益

### 1.3 风险管理六个过程（必记）

> 记忆口诀：**规划识别定性定量应对控制**

1. **风险管理规划** - 制定风险管理计划
2. **风险识别** - 识别可能影响项目的风险
3. **定性风险分析** - 按概率和影响排优先级
4. **定量风险分析** - 量化分析（数据、模型）
5. **风险应对** - 制定应对策略
6. **风险控制** - 监控风险、执行应对

### 1.4 风险识别

#### 风险登记册★★★
- **开始于**：风险识别过程
- **供使用**：其他风险管理过程、项目管理过程
- **应包括**：
  - 已识别的风险清单
  - 潜在的应对措施清单

#### 识别风险的工具和技术

| 工具 | 特点 |
|------|------|
| 核对单分析 | 简单易用但无法穷尽所有事项 |
| 专家判断 | 依赖经验 |
| 文档审查 | 对项目文档进行结构化审查 |
| 头脑风暴 | 团队集思广益 |
| 德尔菲技术 | 匿名、多轮反馈、意见趋向一致 |
| SWOT分析 | 优势/劣势/机会/威胁 |
| 假设分析 | 验证假设条件 |

#### 德尔菲技术（必记）
**特点**：依赖专家经验、匿名、多轮反馈
**优点**：
- 避免权威人士过大影响
- 减轻数据偏差，准确性高
- 避免情面、自尊问题

**缺点**：过程复杂，花费时间长

### 1.5 风险应对策略★★★

| 策略 | 含义 | 示例 | 适用 |
|------|------|------|------|
| **规避** | 完全消除风险可能 | 取消有风险的工作 | 高影响风险 |
| **减轻** | 降低风险概率或影响 | 多测试、提前准备人员 | 高影响风险 |
| **转移** | 将风险后果转给第三方 | 买保险、外包 | 低影响风险 |
| **接受** | 承认风险，准备应急预案 | 制定应急计划 | 低影响风险 |

> **关键区分**：
> - 规避 = 风险可能性**完全消除**
> - 减轻 = 降低概率或影响（多测试、培训等）
> - 转移 = 第三方承担（保险、外包）
> - 接受 = 准备预案但不主动处理

> **排序**：高影响→规避/减轻，低影响→转移/接受

### 1.6 定量风险分析

**工具与技术**：
- 数据收集和表示
- 敏感性分析
- 预计货币价值分析（EMV）
- 蒙特卡洛模拟
- 专家判断

## 二、沟通管理

### 2.1 沟通管理形式（参与程度从高到低）

| 形式 | 参与程度 | 控制程度 |
|------|---------|---------|
| 参与/讨论 | 最高 | 最低 |
| 征询 | 高 | 低 |
| 说明/推销 | 低 | 高 |
| 叙述 | 最低 | 最高 |

### 2.2 沟通渠道公式
```
沟通渠道数 = n(n-1)/2
```

### 2.3 沟通管理案例题答题模板

**存在的问题**：
1. 缺少沟通管理计划
2. 未取得客户/高层支持
3. 沟通方式单一，应针对不同干系人需求提供对应信息
4. 冲突管理存在问题（如强制手段制止抱怨）
5. 对干系人提出的需求未给出满意答复
6. 对高层的沟通未取得支持
7. 沟通情况未做记录

## 三、干系人管理

### 3.1 干系人管理四个过程（必记）

> 记忆：**识别、计划、管理、监控**

1. **识别干系人**
2. **编制干系人管理计划**
3. **管理干系人参与**
4. **监控干系人参与**

### 3.2 识别干系人

| 类别 | 内容 |
|------|------|
| 输入 | 项目章程、采购文件、事业环境因素、组织过程资产 |
| 工具与技术 | 干系人分析、专家判断、会议 |
| 输出 | 干系人登记册 |

### 3.3 权力/利益方格（管理策略）★★★

```
         高权力
    ┌─────────────────┐
    │ 令其满意  │ 重点管理  │
    │(高权低利) │(高权高利) │
    ├─────────────────┤
    │   监督    │ 随时告知  │
    │(低权低利) │(低权高利) │
    └─────────────────┘
低利益              高利益
```

| 权力 | 利益 | 策略 |
|------|------|------|
| 高 | 高 | **重点管理** |
| 高 | 低 | **令其满意** |
| 低 | 高 | **随时告知** |
| 低 | 低 | **监督** |

### 3.4 干系人分类四大模型

| 模型 | 分类依据 |
|------|---------|
| 权力/利益方格 | 职权大小 + 对结果的关注程度 |
| 权力/影响方格 | 职权大小 + 主动参与程度 |
| 影响/作用方格 | 主动参与程度 + 改变项目能力 |
| 凸显模型 | 权力 + 兴趣 + 合法性 |

### 3.5 干系人清单补充（案例题）
- 题目中提到的所有人
- 看看有没有遗漏**甲方用户**
- 万能答案：**其他受影响的组织或个人**

## 四、案例题答题模板

### 4.1 风险管理存在的问题（模板）

1. 应全体项目成员共同参与风险管理，不能一人处理
2. 缺乏风险管理意识/未配置专职风险管理人员
3. 没有加强风险管理的培训
4. 未进行定性/定量风险分析
5. 未定期对风险进行再识别
6. 风险应对措施不全面/不够有效
7. 风险应对措施没有责任分配到人
8. 缺少风险登记册（已识别风险清单+潜在应对措施）
9. 风险管理应在启动/计划/管理/监控/收尾阶段持续进行

### 4.2 干系人管理存在的问题（模板）

1. 干系人识别不完整，遗漏了XX
2. 未编制干系人管理计划
3. 未根据权力/利益分类采取不同管理策略
4. 未有效管理干系人参与
5. 未定期监控干系人参与度
6. 沟通不充分，未满足干系人信息需求

   **答案：B**
