## 一、项目管理基础框架

### 1.1 项目的三个特点
1. **临时性** - 有明确开始和结束时间
2. **独特性** - 独特的产品、服务或成果
3. **渐进明细** - 成果逐步完善

### 1.2 项目目标
- **成果性目标**（项目目标）：满足客户要求的产品/系统/服务
- **约束性目标**（管理性目标）：时间、费用

### 1.3 五大过程组（必记）

| 过程组 | 核心任务 | 关键词 |
|--------|---------|--------|
| 启动 | 定义项目/阶段，授权 | 授权、章程 |
| 规划 | 明确范围、目标，制定计划 | 计划、基准 |
| 执行 | 完成管理计划中的工作 | 实施、交付 |
| 监控 | 跟踪、审查、调整 | 偏差、变更 |
| 收尾 | 正式完成项目 | 验收、归档 |

> **考点**：工作量分布 - 执行阶段最大，启动和收尾最小

### 1.4 项目组织类型（按项目经理权限从小到大）

**职能型 → 弱矩阵 → 平衡矩阵 → 强矩阵 → 项目型**

| 类型 | 项目经理权限 | 特点 |
|------|-------------|------|
| 职能型 | 很小/无 | PM受制于职能经理 |
| 弱矩阵 | < 职能经理 | 兼具职能和项目特征 |
| 平衡矩阵 | = 职能经理 | 双重汇报 |
| 强矩阵 | > 职能经理 | PM权力较大 |
| 项目型 | 很大 | 精兵强将集结 |

### 1.5 项目经理的5种权力
1. **职位权力** - 来源于组织中的职位和正式授权
2. **惩罚权力** - 负面手段，谨慎使用
3. **奖励权力** - 激励员工
4. **专家权力** - 来源于专业技能
5. **参照权力** - 个人魅力、榜样力量

## 二、项目整体管理（6个过程）

### 2.1 制定项目章程

**作用**：
- 授权项目经理
- 确认项目存在和目标
- 体现高层管理者原则性要求

**重要规则**：
- 由**发起人（或高层管理者）发起**
- 项目经理**不能发起**，但可参与起草

| 类别 | 内容 |
|------|------|
| 输入 | 工作说明书(SOW)、可行性论证、协议(合同) |
| 工具与技术 | 引导技术、专家判断 |
| 输出 | 项目章程 |

### 2.2 制定项目管理计划

**作用**：生成核心文件，作为所有项目工作的依据

**特点**：渐进明细

| 类别 | 内容 |
|------|------|
| 输入 | 项目章程 |
| 工具与技术 | 专家判断 |
| 输出 | 项目管理计划（含三大基准 + 13个子计划） |

**三大基准**（必记）：
1. **范围基准** = 项目范围说明书 + WBS + WBS词典
2. **进度基准** = 批准的进度计划
3. **成本基准** = 各活动批准预算的总和

**预算结构**：
```
总预算 = 成本基准 + 管理储备
成本基准 = 直接成本 + 间接成本 + 应急储备
```

> **考点**：动用应急储备不改变基准；动用管理储备会改变成本基准

### 2.3 指导与管理项目工作

| 类别 | 内容 |
|------|------|
| 输入 | 项目管理计划、批准的变更请求 |
| 工具与技术 | 会议、项目管理信息系统、专家判断 |
| 输出 | 可交付成果、工作绩效数据、变更请求 |

### 2.4 监控项目工作

| 类别 | 内容 |
|------|------|
| 输入 | 项目管理计划、进度/成本预测、确认的变更、工作绩效信息 |
| 工具与技术 | 分析技术、会议、专家判断 |
| 输出 | 变更请求、工作绩效报告 |

### 2.5 实施整体变更控制

**变更原因**：
- 范围定义过失/疏忽
- 客户提出新需求
- 应对风险
- 执行与基线不一致
- 团队人员调整
- 技术革新
- 外部事件（政策变动）

| 类别 | 内容 |
|------|------|
| 输入 | 项目管理计划、变更请求、工作绩效报告 |
| 工具与技术 | 会议、变更控制工具、专家判断 |
| 输出 | 批准的变更请求、变更日志 |

### 2.6 结束项目或阶段

**收尾分类**（必记）：

| | 合同收尾 | 行政收尾 |
|--|---------|---------|
| 顺序 | 在前 | 在后 |
| 方向 | 对外 | 对内 |
| 次数 | 一次 | 多次 |

## 练习题

1. 在（）组织中，项目经理的权力最大？
   A. 职能型 B. 弱矩阵 C. 强矩阵 D. 项目型
   **答案：D**

2. 项目章程应由（）发布？
   A. 项目经理 B. 项目发起人 C. 项目团队 D. CCB
   **答案：B**

3. 动用管理储备后，（）会发生变化。
   A. 进度基准 B. 成本基准 C. 范围基准 D. 以上都不变
   **答案：B**

4. 合同收尾在行政收尾（）进行。
   A. 之前 B. 之后 C. 同时 D. 不确定
   **答案：A**
