## 学习策略

### 上午题策略
- 前30题：信息化、技术概念 -> 靠记忆
- 中30题：项目管理核心知识 -> 靠理解+记忆
- 后15题：计算+英语 -> 靠公式+技巧
- **目标：确保50题以上正确**

### 下午题策略
- 第1题：通常为管理类案例分析（找问题+建议）
- 第2题：通常含计算（挣值或网络图）
- 第3题：综合管理案例
- 第4题：计算或综合案例
- **重点训练：计算题确保全对，分析题用模板答**

### 答题技巧
1. 计算题写公式、写过程、写单位
2. 分析题多写要点（踩点给分）
3. 不确定的判断题优先选"对"
4. 上午选择题看上下文判断章节
5. 英语题看关键词重复度

## 核心公式速查

```
挣值分析：
  EV = 实际完成工作 × 预算单价
  PV = 计划完成工作 × 预算单价
  AC = 实际花费
  CPI = EV/AC （>1节约，<1超支）
  SPI = EV/PV （>1提前，<1滞后）
  CV = EV-AC
  SV = EV-PV
  EAC = BAC/CPI（典型偏差）
  EAC = AC+BAC-EV（非典型偏差）
  ETC = BAC-EV（非典型）
  ETC = (BAC-EV)/CPI（典型）
  VAC = BAC-EAC

三点估算PERT：
  期望 = (O+4M+P)/6
  标准差 = (P-O)/6
  正态分布：±1σ=68%, ±2σ=95%, ±3σ=99.7%

沟通渠道：n(n-1)/2

网络图：
  总浮动 = LS-ES = LF-EF
  自由浮动 = 紧后ES - 本活动EF
```
