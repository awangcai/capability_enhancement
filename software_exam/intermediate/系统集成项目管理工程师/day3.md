## 一、进度网络图计算

### 1.1 六时图计算步骤

**例题**：活动A(3天)→B(4天)→D(2天)，A(3天)→C(5天)→D(2天)

```
步骤1 正推（求ES/EF）：
  A: ES=0, EF=0+3=3
  B: ES=3, EF=3+4=7
  C: ES=3, EF=3+5=8
  D: ES=max(7,8)=8, EF=8+2=10

步骤2 逆推（求LS/LF）：
  D: LF=10, LS=10-2=8
  B: LF=8, LS=8-4=4
  C: LF=8, LS=8-5=3
  A: LF=min(4,3)=3, LS=3-3=0

步骤3 计算浮动：
  A: 总浮动=0-0=0 ★关键
  B: 总浮动=4-3=1
  C: 总浮动=3-3=0 ★关键
  D: 总浮动=8-8=0 ★关键
  
关键路径：A→C→D，工期=10天
```

> **核心规则**：
> - 正推：多个前驱取**最大**EF
> - 逆推：多个后继取**最小**LS
> - 总浮动=0的活动在关键路径上

### 1.2 工期压缩题型

**解题步骤**：
1. 找出关键路径
2. 计算关键路径上各活动的「可压缩天数」和「每天增加费用」
3. 优先压缩每天费用**最小**的活动
4. 注意：压缩后可能产生新的关键路径
5. 计算净增支出 = 压缩费用 - 节省的间接费用×压缩天数

### 1.3 最少资源人数题型

**解题步骤**：
1. 画出时标网络图
2. 标注每个时间段各活动并行数/人数
3. 利用自由时差移动非关键路径活动
4. 找到人数最少的安排方案

## 二、三点估算PERT

### 2.1 公式

```
β分布（默认）：
  期望时间 Te = (O + 4M + P) / 6

三角分布（题目会说明）：
  期望时间 Te = (O + M + P) / 3

标准差 σ = (P - O) / 6
```

- O = 乐观估算（Optimistic）
- M = 最可能估算（Most likely）
- P = 悲观估算（Pessimistic）

### 2.2 正态分布概率

```
±1σ → 68.26%
±2σ → 95.46%
±3σ → 99.73%
```

单侧面积分布：34% / 13% / 2%

**典型题目**：在XX天内完成的概率是多少？
1. 算出期望时间Te
2. 算出标准差σ
3. 看目标时间在Te ± 几个σ的位置
4. 查表得概率

## 三、成本管理

### 3.1 成本分类

| 类型 | 举例 |
|------|------|
| 直接成本 | 差旅费、工资、项目物料、设备使用费 |
| 间接成本 | 其他部门工资、税金、福利、保卫费用 |

### 3.2 成本估算方法
- 专家判断
- 类比估算（自上而下，快但不准）
- 参数估算（取决于参数模型成熟度）
- 自下而上估算（最准确，最耗时）
- 三点估算
- 储备分析

### 3.3 成本失控原因
- 对工程项目认识不足
- 组织制度不健全
- 方法问题
- 技术制约（估算方法不恰当、与实际不符）

## 四、挣值分析（EVM）★★★★★

### 4.1 三个基本值

| 缩写 | 含义 | 计算方法 |
|------|------|---------|
| **PV** | 计划值 | 到目前为止**计划**应完成工作的预算 |
| **EV** | 挣值 | 到目前为止**实际**已完成工作的预算 |
| **AC** | 实际成本 | 到目前为止实际花费的金额 |

> **理解技巧**：
> - PV = 计划做了多少（用预算金额衡量）
> - EV = 实际做了多少（用预算金额衡量）
> - AC = 实际花了多少钱

### 4.2 绩效指数

| 指标 | 公式 | 判断标准 |
|------|------|---------|
| **CPI** 成本绩效指数 | EV / AC | >1节约, <1超支 |
| **SPI** 进度绩效指数 | EV / PV | >1提前, <1滞后 |

### 4.3 偏差

| 指标 | 公式 | 判断标准 |
|------|------|---------|
| **CV** 成本偏差 | EV - AC | >0节约, <0超支 |
| **SV** 进度偏差 | EV - PV | >0提前, <0滞后 |

> **记忆技巧**：EV在所有公式中都是被减数或分子（挣值是核心）

### 4.4 预测值

| 指标 | 非典型偏差 | 典型偏差 |
|------|-----------|---------|
| **ETC** 完工尚需估算 | BAC - EV | (BAC - EV) / CPI |
| **EAC** 完工估算 | AC + BAC - EV | BAC / CPI |
| **VAC** 完工偏差 | BAC - EAC | BAC - EAC |

- **非典型偏差**：后期不会出现相同情况（偏差是偶然的）
- **典型偏差**：会按照当前绩效持续发展下去

> **考试提醒**：案例题计算EAC时，必须先判断是典型还是非典型偏差，写出判断依据！

### 4.5 完整公式汇总

```
基本值：PV, EV, AC, BAC（总预算）

绩效指数：
  CPI = EV / AC
  SPI = EV / PV

偏差：
  CV = EV - AC
  SV = EV - PV

预测（非典型）：
  ETC = BAC - EV
  EAC = AC + BAC - EV = AC + ETC
  
预测（典型）：
  ETC = (BAC - EV) / CPI
  EAC = BAC / CPI

完工偏差：
  VAC = BAC - EAC（正值盈利，负值亏损）
```

### 4.6 挣值分析案例题答题模板

```
1. 列出已知数据（PV、AC、完成百分比、BAC）
2. 计算EV = 实际完成百分比 × BAC（或逐项计算）
3. 计算CPI = EV/AC = xxx
4. 计算SPI = EV/PV = xxx
5. 结论：
   CPI < 1，成本超支
   SPI < 1，进度滞后
6. 如需预测：
   判断偏差类型（典型/非典型）
   计算EAC = ...
   计算VAC = BAC - EAC = ...
```

### 4.7 常见情境与对策

| 情况 | 对策 |
|------|------|
| 进度滞后+成本节约 | 赶工、使用高效资源、改进方法 |
| 进度滞后+成本超支 | 赶工+快速跟进、更好资源、减少范围 |
| 进度超前+成本超支 | 抽出人员放慢进度、成本控制 |
| 进度超前+成本节约 | 抽调人员、加强质量监控 |

**赶进度的措施**：
1. 赶工（增加资源）
2. 快速跟进（并行施工）
3. 使用高素质资源/经验丰富人员
4. 改进方法或技术
5. 加强质量管理减少返工
6. 经客户许可减少范围

## 五、沟通渠道计算

```
沟通渠道数 = n(n-1)/2
```

> 注意：如果自己是项目经理且参与项目，要把自己算进n里

**扩展题型**：计算开发月数
```
每月实际产出 = 人数×每人月产出 - 沟通成本×渠道数
所需月数 = 总工作量 / 每月实际产出
```

## 综合练习题

**题目**：某项目BAC=100万，计划工期10个月。第5个月末检查：PV=50万，AC=60万，EV=40万。

1. 计算CPI和SPI？
2. 项目成本和进度状况如何？
3. 假设为典型偏差，计算EAC？
4. 完工偏差VAC？

**解答**：
```
1. CPI = EV/AC = 40/60 = 0.67
   SPI = EV/PV = 40/50 = 0.8

2. CPI=0.67 < 1，成本超支
   SPI=0.8 < 1，进度滞后

3. 典型偏差：EAC = BAC/CPI = 100/0.67 = 149.25万元

4. VAC = BAC - EAC = 100 - 149.25 = -49.25万元
   即完工时将超支49.25万元
```
