## 二、高频易错知识点

### 2.1 容易混淆的概念

| 容易混淆 | 正确理解 |
|---------|---------|
| 项目章程 vs 项目管理计划 | 章程=授权文件，计划=执行依据 |
| 确认范围 vs 质量控制 | 确认范围=验收，质量控制=检验正确性 |
| 资源平滑 vs 资源平衡 | 平滑不改工期，平衡可能延长 |
| 应急储备 vs 管理储备 | 应急=已识别风险(含在基准内)，管理=未预见(不含在基准内) |
| 纠正措施 vs 预防措施 | 纠正=当前一致，预防=未来一致 |
| 合同收尾 vs 行政收尾 | 合同=对外/先/一次，行政=对内/后/多次 |
| 总浮动 vs 自由浮动 | 总=不影响完工，自由=不影响紧后活动 |
| 典型偏差 vs 非典型偏差 | 典型=会持续，非典型=偶然 |

### 下午题模拟

**案例题**：

某项目预算BAC=200万元，工期12个月。第6个月末检查发现：
- 计划完成60%的工作
- 实际完成50%的工作
- 实际花费130万元
- 项目经理认为后期效率会保持当前水平

**问题1**：计算PV、EV、AC、CPI、SPI、CV、SV，评估项目当前状态。

**问题2**：预测EAC、ETC、VAC。

**问题3**：针对当前状况，应采取哪些措施？

**参考答案**：

问题1：
```
BAC = 200万元
PV = 200 × 60% = 120万元
EV = 200 × 50% = 100万元
AC = 130万元

CPI = EV/AC = 100/130 = 0.77
SPI = EV/PV = 100/120 = 0.83
CV = EV-AC = 100-130 = -30万元
SV = EV-PV = 100-120 = -20万元

结论：
CPI=0.77<1，成本超支，已超支30万元
SPI=0.83<1，进度滞后，进度落后相当于20万元的工作量
```

问题2：
```
项目经理认为后期效率会保持当前水平，属于典型偏差。

EAC = BAC/CPI = 200/0.77 = 259.74万元
ETC = EAC-AC = 259.74-130 = 129.74万元
   或 ETC = (BAC-EV)/CPI = (200-100)/0.77 = 129.87万元
VAC = BAC-EAC = 200-259.74 = -59.74万元

结论：按当前趋势，完工时预计总花费259.74万元，超支59.74万元
```

问题3：
```
当前进度滞后、成本超支，应采取以下措施：
1. 赶工，增加资源投入以追赶进度
2. 快速跟进，安排可并行的工作同时进行
3. 使用高素质资源或更有经验的人员替换效率低的人员
4. 改进工作方法或技术，提高工作效率
5. 加强质量管理，减少返工带来的时间和成本浪费
6. 加强成本监控，对成本超支原因进行分析并控制
7. 在客户许可的前提下，减少活动范围或降低活动要求
8. 对项目进度进行重新规划，必要时通过变更流程调整基准
```
