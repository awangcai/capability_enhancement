## 一、项目质量管理

### 1.1 质量管理四个过程

| 过程 | 作用 | 关键词 |
|------|------|--------|
| 质量规划 | 确定标准、制定计划 | 规划、标准 |
| 质量保证 | 增强满足质量要求的能力 | 审核、预防 |
| 质量控制 | 检测验证阶段成果 | 检测、纠正 |
| 质量改进 | 持续提升质量水平 | 改进、优化 |

> **区分重点**：
> - 质量保证 = 事前预防（审核、维护、培训）→ 按计划检查属于保证
> - 质量控制 = 事后检验（测试、检查）→ 测试工作属于控制

### 1.2 质量规划

**输出**（必记）：
1. 质量核对单
2. 质量测量指标
3. 质量管理计划
4. 过程改进计划
5. 项目文件更新

### 1.3 质量保证（质量审计）

**目标**：
- 识别全部正在实施的良好及最佳实践
- 识别全部违规做法、差距、不足
- 分享良好实践
- 积极协助改进执行效率
- 每次审计贡献经验教训

### 1.4 质量控制

**输入**：
- 质量测量指标、质量核对单
- 工作绩效数据
- 批准的变更请求
- 可交付成果
- 项目文件、组织过程资产、事业环境因素

**输出**：
- 质量控制测量结果
- **核实的可交付成果**（检查没问题可以交付）
- 工作绩效信息
- 变更请求
- 管理计划/组织过程资产更新

### 1.5 质量成本（必记）

```
质量成本
├── 一致性成本（防止失败）
│   ├── 预防成本：培训、流程文档化、购买设备
│   └── 评价成本：测试、检查、破坏性测试损失
└── 非一致性成本（处理失败）
    ├── 内部失败成本：返工、废品
    └── 外部失败成本：客户责任、保修、业务变更
```

> 记忆口诀：**预防评价，内部外部**

### 1.6 质量控制七工具（老版）★★★

| 工具 | 用途 | 特征 |
|------|------|------|
| **因果图**（鱼骨图） | 识别**所有**原因 | 鱼骨形状 |
| **流程图** | 了解过程质量成本 | 流程方框 |
| **核查表** | 收集潜在质量问题数据 | 查对清单 |
| **控制图** | 监测过程是否在控制状态 | 有上下控制界限 |
| **散点图** | 分析原因和测量值关系 | (X,Y)数据对 |
| **直方图** | 反映集中趋势、分散程度 | 条形图 |
| **帕累托图** | 找出少数主要问题（二八法则） | 条形+折线组合 |

> **考点区分**：
> - 帕累托图 → 关键词"主要原因""二八法则""少数问题"
> - 直方图 → 关键词"集中趋势""分散程度"
> - 因果图 → 关键词"所有原因""鱼骨"
> - 控制图 → 关键词"控制界限""监测过程"

> 记忆口诀：**因果 流程 核查表，控制 散点 直方 帕累托**

## 二、人力资源管理

### 2.1 人力资源管理计划的工具与技术
- 组织结构图
- 职位描述
- 人际交往
- 组织理论
- 会议
- 专家判断

### 2.2 团队组建

**输入**：组织结构、人力资源管理计划

**工具与技术**（必记）：
1. **预分派** - 事先确定人员
2. **谈判** - 与职能经理协商
3. **招募** - 外部招聘
4. **虚拟团队** - 远程协作
5. **多标准决策分析** - 多维评估

**输出**：
- 项目人员分配表
- 资源日历
- 项目管理计划更新

### 2.3 团队建设

**工具与技术**：
- 人际关系培养
- 培训
- 团队建设活动
- 集中办公
- **认可和奖励**（属于团队建设，非人力资源管理）
- 制定基本规则

### 2.4 马斯洛需求层次理论

```
5. 自我实现需求 ← 最高层
4. 受尊重需求
3. 社会交往需求
2. 安全需求
1. 生理需求 ← 最低层
```

### 2.5 冲突管理

#### 冲突的特点
- 冲突是自然的，要找出解决办法
- 冲突是**团队问题**，不是个人问题
- 应**公开**处理冲突
- 聚焦于**解决问题**，不是人身攻击
- 聚焦于**现在**，不是过去

#### 冲突解决方法（必记）

| 方法 | 特点 | 适用场景 |
|------|------|---------|
| **解决问题/合作** | 深入各方需要，满足所有人 | 最佳方式，双赢 |
| **妥协** | 各方让步，无人完全满意 | 时间紧迫 |
| **强制** | 一方意见压倒另一方 | 紧急情况 |
| **求同存异（缓和）** | 强调共同点，搁置分歧 | 暂时缓解 |
| **撤退（回避）** | 暂时搁置，推迟处理 | 冷静期 |

## 三、案例题答题模板

### 3.1 人力资源管理存在的问题（模板）

1. 应全体项目成员共同参与规划，不能一个人规划
2. 缺乏XX管理意识/XX工程师必须专职
3. 依据不足，缺少项目管理计划/XX管理计划
4. 客户/高层不满 → 沟通管理存在问题
5. 组建团队未充分考虑项目需求、角色和职责
6. 应进行人际关系培养、培训、团队建设、认可和奖励
7. 缺少明确考核标准
8. 未公正公开处理冲突
9. 缺少应急预案
10. 未对进度进行监控和偏差分析

### 3.2 质量管理存在的问题（模板）

1. 应全体干系人共同参与质量规划
2. 缺乏质量管理意识
3. 依据不足，缺少质量管理计划
4. 输出不足，缺少过程改进计划/质量核对单
5. 未进行评审就直接执行
6. 未采用合理工具与技术
7. 未收集质量管理过程中的绩效数据
8. 质量控制输入不完整（缺少质量测量指标等）
