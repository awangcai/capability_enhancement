## 一、挣值分析练习

### 题目1：基础挣值计算

某项目有A、B、C三个子任务，情况如下：

| 任务 | 预算(万元) | 计划完成% | 实际完成% | 实际花费(万元) |
|------|-----------|----------|----------|--------------|
| A | 20 | 100% | 100% | 22 |
| B | 30 | 100% | 80% | 28 |
| C | 50 | 50% | 30% | 20 |

BAC = 20+30+50 = 100万元

**求：PV、EV、AC、CPI、SPI？项目状态如何？**

**解答**：
```
PV = 20×100% + 30×100% + 50×50% = 20+30+25 = 75万元
EV = 20×100% + 30×80% + 50×30% = 20+24+15 = 59万元
AC = 22+28+20 = 70万元

CPI = EV/AC = 59/70 = 0.84 < 1 → 成本超支
SPI = EV/PV = 59/75 = 0.79 < 1 → 进度滞后

CV = EV-AC = 59-70 = -11万元（超支11万元）
SV = EV-PV = 59-75 = -16万元（进度落后16万元工作量）
```

### 题目2：完工估算

接上题，假设偏差为典型偏差，求EAC和VAC。

```
EAC = BAC/CPI = 100/0.84 = 119.05万元
VAC = BAC-EAC = 100-119.05 = -19.05万元

结论：按当前趋势发展，完工时将超支约19.05万元
```

若为非典型偏差：
```
EAC = AC+BAC-EV = 70+100-59 = 111万元
VAC = BAC-EAC = 100-111 = -11万元
```

### 题目3：合同盈亏分析

某项目合同金额120万元，BAC=100万元。典型偏差，CPI=0.84。

```
EAC = BAC/CPI = 100/0.84 = 119.05万元
利润 = 合同金额 - EAC = 120 - 119.05 = 0.95万元

结论：按当前趋势，完工时仍有0.95万元利润
```

## 二、关键路径计算练习

### 题目4：六时图计算

活动表：

| 活动 | 工期(天) | 紧前活动 |
|------|---------|---------|
| A | 3 | - |
| B | 4 | A |
| C | 6 | A |
| D | 2 | B |
| E | 3 | B,C |
| F | 4 | D,E |

**求：关键路径、总工期、各活动浮动时间**

**解答**：

```
步骤1 画网络图：
  开始→A→B→D→F→结束
  开始→A→C→E→F→结束
  B→E也有连线

步骤2 正推（ES/EF）：
  A: ES=0, EF=3
  B: ES=3, EF=7
  C: ES=3, EF=9
  D: ES=7, EF=9
  E: ES=max(7,9)=9, EF=12
  F: ES=max(9,12)=12, EF=16

步骤3 逆推（LS/LF）：
  F: LF=16, LS=12
  D: LF=12, LS=10
  E: LF=12, LS=9
  C: LF=9, LS=3
  B: LF=min(10,9)=9, LS=5
  A: LF=min(5,3)=3, LS=0

步骤4 计算浮动：
  A: 0-0=0 ★
  B: 5-3=2
  C: 3-3=0 ★
  D: 10-7=3
  E: 9-9=0 ★
  F: 12-12=0 ★

关键路径：A→C→E→F，总工期=16天
```

### 题目5：工期压缩

接上题，要求压缩2天。各活动可压缩信息：

| 活动 | 可压缩天数 | 每天增加费用(万元) |
|------|-----------|------------------|
| A | 1 | 3 |
| C | 2 | 2 |
| E | 1 | 4 |
| F | 2 | 5 |

间接费用：每天1万元

```
分析：关键路径为A→C→E→F

方案：优先压缩费用最低的活动
1. 压缩C 1天：增加2万元
2. 压缩C 1天：增加2万元（C最多压缩2天，第二天继续C）
   或压缩A 1天：增加3万元

最优方案：压缩C 2天
增加费用 = 2+2 = 4万元
节省间接费用 = 1×2 = 2万元
净增支出 = 4-2 = 2万元

注意：压缩后检查是否产生新关键路径！
原路径A→B→E→F = 3+4+3+4 = 14天
压缩后A→C→E→F = 3+4+3+4 = 14天 → 变为关键路径！

结论：C压缩2天后工期变为14天，且产生了新关键路径A→B→E→F
```

### 题目6：浮动时间与延误

某项目关键路径ABDF=20天。活动E不在关键路径上，总浮动时间为3天。

Q1：E延误2天，总工期延迟多少？
```
延迟 = max(0, 2-3) = 0天（不延迟）
```

Q2：E延误5天，总工期延迟多少？
```
延迟 = 5-3 = 2天
```

## 三、三点估算PERT练习

### 题目7：估算与概率

某活动：乐观时间O=5天，最可能M=8天，悲观时间P=17天

```
期望时间 Te = (5+4×8+17)/6 = (5+32+17)/6 = 54/6 = 9天
标准差 σ = (17-5)/6 = 12/6 = 2天
```

Q：在11天内完成的概率？
```
11天 = Te + 1σ = 9 + 2 = 11
所以在均值+1σ处
概率 = 50% + 34% = 84%
```

Q：在13天内完成的概率？
```
13天 = Te + 2σ = 9 + 4 = 13
概率 = 50% + 47.5% = 97.5%（约95%左右）
```

### 题目8：关键路径+PERT组合

路径1（关键路径）各活动期望时间之和=30天，各活动标准差：2,1,1,2
路径标准差 = √(2²+1²+1²+2²) = √(4+1+1+4) = √10 ≈ 3.16天

Q：在33.16天内完成的概率？
```
33.16 = 30 + 3.16 = Te + 1σ
概率 ≈ 84%
```

## 四、沟通渠道练习

### 题目9

项目有8名成员（含项目经理），新增2人后沟通渠道增加了多少？

```
原来：n=8, 渠道=8×7/2=28条
现在：n=10, 渠道=10×9/2=45条
增加：45-28=17条
```

### 题目10：开发月数计算

项目需完成10000功能点，团队5人，每人每月完成500功能点，每条沟通渠道每月消耗50功能点。

```
沟通渠道 = 5×4/2 = 10条
每月沟通消耗 = 10×50 = 500功能点
每月实际产出 = 5×500 - 500 = 2500-500 = 2000功能点
所需月数 = 10000/2000 = 5个月
```

## 五、自购/外购分析

### 题目11

自行开发：固定成本20万，变动成本800元/功能点
外购方案A：单价2000元/功能点
外购方案B：固定费5万，单价1500元/功能点

项目需要200个功能点，哪种方案最优？

```
自行开发：20万 + 800×200 = 20万+16万 = 36万元
外购A：2000×200 = 40万元
外购B：5万 + 1500×200 = 5万+30万 = 35万元

结论：外购B最优（35万元）
```

## 六、加权评分法

### 题目12

3位评委对项目进行评分，权重如下：

| 指标 | 权重 | 评委1 | 评委2 | 评委3 |
|------|------|-------|-------|-------|
| 技术方案 | 0.4 | 85 | 90 | 80 |
| 项目管理 | 0.3 | 90 | 85 | 88 |
| 商务报价 | 0.3 | 92 | 88 | 90 |

```
技术方案平均分 = (85+90+80)/3 = 85分
项目管理平均分 = (90+85+88)/3 = 87.67分
商务报价平均分 = (92+88+90)/3 = 90分

加权总分 = 85×0.4 + 87.67×0.3 + 90×0.3
         = 34 + 26.3 + 27 = 87.3分
```

### 挣值分析答题标准格式：
```
PV = ... = XX万元
EV = ... = XX万元
AC = ... = XX万元
CPI = EV/AC = XX/XX = X.XX
SPI = EV/PV = XX/XX = X.XX
因为CPI<1，所以成本超支
因为SPI<1，所以进度滞后
（判断偏差类型：典型/非典型）
EAC = BAC/CPI = XX万元
VAC = BAC-EAC = XX万元（正值盈利，负值亏损）
```

```
假设项目开始时间为第0天（日）

总浮动时间 = LS-ES = X天
关键路径为：A→C→E→F
项目最短工期为：X天
```
